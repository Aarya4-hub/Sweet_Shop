

# Sweet Delights 🍬

A simple **HTML, CSS, and JavaScript** project showcasing a sweet shop landing page with product cards and a basic cart simulation.

## Features
- Responsive header with navigation links.
- Product cards with images, names, and "Add to Cart" buttons.
- JavaScript-powered cart section that updates dynamically.
- Clean and colorful design with a sweet-themed palette.

## Tech Stack
- **HTML5** for structure
- **CSS3** for styling
- **JavaScript (ES6)** for interactivity

## Setup
1. Clone or download the project files.
2. Open `index.html` in any modern browser.
3. Click on products to add them to the cart.
